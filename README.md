## Sobre o projeto

Uma calculadora simples desenvolvida em Java para Android.

O app faz as contas básicas do dia a dia, bloqueia números grandes demais para não quebrar o layout e avisa quando acontece algum cálculo inválido (como divisão por zero).

## Funcionalidades

- Teclado numérico completo (0 a 9)
- As 4 operações básicas:
    - Soma (+)
    - Subtração (-)
    - Multiplicação (*)
    - Divisão (/)
- Limite de 7 dígitos por número
- Mensagem de `ERROR` na tela se passar do limite ou dividir por zero
- Botão `Limpar` para zerar tudo
- Botão `=` para ver o resultado
